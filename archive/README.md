# Archive: legacy Flutter app (`athan_app_v2`)

The original Flutter implementation lives in `flutter-app/` (history preserved
via `git mv`). It is **not built or maintained**, and the current app does not
use any of its code.

The active app is the native Android (Jetpack Compose) project at the
repository root; see the main [README](../README.md).

`MIGRATION_NOTES.md` is the checklist used while porting features from the
Flutter app to the native one, kept for history.
